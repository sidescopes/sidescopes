# Brand assets

The SideScopes mark: six vectorscope target hues on the vertices of the
gamut hexagon, parallel channels between them, and a square aperture in
the middle — the region of the screen being measured.

## What is here

| File | Used for |
| --- | --- |
| `icons/macos/sidescopes.icns` | the macOS bundle icon, plated |
| `icons/windows/sidescopes.ico` | the Windows executable icon, free-form |
| `icons/linux/sidescopes-{s}.png` | `hicolor/{s}x{s}/apps/sidescopes.png`, once there is a Linux package |
| `svg/*.svg` | the masters everything else is drawn from |

Targets: R `#f2452f` · Y `#f0b400` · G `#17b84a` · C `#16b8d4` ·
B `#2f4fe8` · M `#e02fae`. Ink `#201e1d`, paper `#f8f4f4`.

The plated cut goes where the icon sits among other application tiles, the
bare mark where the background is ours, and the flat wide-channel cut at 32
pixels and below, which is what the icon files carry at those sizes. Do not
recolor the targets, rotate the mark, or close the channels. The lockups
carry the wordmark as outlines, set in Archivo ExtraBold, so they render
the same with or without the font installed.
